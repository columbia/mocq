## Rules
- Do NOT change `@name`, `@id`, `@kind`, `@precision`, or the alert message string.
- Keep `@kind path-problem` and the path-node `select` shape.
- Define top-level `predicate mocqSource(DataFlow::Node)` and `predicate mocqSink(DataFlow::Node)` and
  route the config through them (the validator decomposes your query via these).
- Keep `mocqSource` / `mocqSink` GENERAL — no identifiers, class names, or route strings copied from
  the example file. Match framework APIs and node kinds only.
- The query must compile. Keep it fast: no unbounded recursion, no cartesian products.

## Steps (do these, nothing else — no summary)
1. Read the example and the seed; decide the source, sink, and any sanitizer for this pattern.
2. `Write` the full query to `{{WIP_PATH}}`.
3. `mcp__codeql__codeql_compile({"query_path": "{{WIP_PATH}}"})`; on failure use
   `mcp__codeql__codeql_diagnostics` / `mcp__codeql__codeql_hover`, fix, write again. Repeat until clean.
4. Stop after a clean compile. Do NOT evaluate the query against any database.

## Disallowed
- Running/evaluating the query (`codeql_run_query`, `database analyze`, `query run`).
- Editing anything other than `{{WIP_PATH}}`.
- Symlinks, modifying the CodeQL installation, force-killing codeql.
